# موسوعة الخصال المائتان في السلوك والآداب والمروءة 📖✨
### جامع المنظومات الأخلاقية والتربوية والأدبية العربية (مع موسوعة إمتاع القارئ)

تطبيق ويب تقدمي (PWA) فاخر لقراءة وتصفح موسوعات الأدب والحِكَم العربية، مع تجربة قراءة فريدة صفحة بصفحة (Page-by-Page)، خطوط عربية تراثية أصيلة (الخط الأميري، رقعة، نسخ، كوفي، شهرزاد)، قوالب أشكال أندلسية وعصرية، وعرض كامل الحواف (Edge-to-Edge).

---

## 🌟 الميزات الرئيسية:
- **موسوعة الخصال المائتان (200 خصلة):** منظومة الثنائيات، الثلاثيات، الرباعيات، الخماسيات، والسداسيات مع الشروح والبيان.
- **موسوعة إمتاع القارئ:** مئات الأبواب والحكم وروائع الأدب العربي.
- **تجربة قراءة فاخرة (Page-by-Page & Scroll):** تقليب صفحات سلس مع مؤشرات تقدم ورقم الصفحة بالعربية.
- **تخصيص كامل للخطوط وتكبير النصوص:** 9 خطوط عربية مع إمكانية تكبير الخط حتى 54 نقطة وضبط تباعد الفقرات.
- **قوالب وهيئات الأشكال (Card & List Shaping):** طابع أندلسي، عصري، مؤطر مذهب، كبسولي، وكلاسيكي هندسي.
- **عرض كامل الحواف (Edge-to-Edge):** استغلال كامل للشاشات بدون هوامش ميتة.
- **أدوات الباحث والقارئ:** التظليل بألوان متعددة، كتابة الملاحظات، حفظ الاقتباسات والمفضلة، البحث اللحظي الدقيق، ومؤقت بومودورو، والأصوات الهادئة.
- **تطبيق تقدمي بدون اتصال (Offline PWA):** حفظ تلقائي وسريع للبيانات محلياً عبر IndexedDB (Dexie).
