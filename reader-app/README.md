# إمتاع القارئ — تطبيق القراءة الرقمي

تطبيق قراءة رقمي فاخر لكتاب "إمتاع القارئ بجمال الكلم وروائع الحكم" مبني بـ React + Vite + TypeScript.

## التشغيل محلياً

```bash
npm install
npm run dev       # خادم التطوير على http://localhost:5173
npm run build     # بناء نسخة الإنتاج في dist/
npm run preview   # معاينة نسخة الإنتاج المبنية
npm run test      # تشغيل الاختبارات (Vitest)
npm run test:watch # تشغيل الاختبارات في وضع المراقبة
```

## البنية

- `src/pages/` — شاشات التطبيق (الرئيسية، المكتبة، القارئ، البحث، الإحصائيات، المحرر...)
- `src/components/reader/` — منطق القارئ: التظليل، الملاحظات، الفهرس، الإعدادات، القراءة الصوتية
- `src/components/ui/` — عناصر واجهة أساسية قابلة لإعادة الاستخدام (فوق Radix UI)
- `src/store/` — حالة Zustand (الإعدادات، موضع القراءة) مع الحفظ في localStorage
- `src/lib/db.ts` — مخطط Dexie (IndexedDB) للتظليلات والملاحظات والعلامات والجلسات
- `src/lib/bookData.ts` — تحميل وفهرسة بيانات الكتاب
- `public/data/book.json` — محتوى الكتاب المُحوَّل من الملف المصدر إلى نموذج الفصول/الكتل
- `scripts/transform.py` — سكربت تحويل ملف JSON الأصلي إلى `public/data/book.json`
- `src/lib/*.test.ts` — اختبارات Vitest لمنطق التطبيع العربي، وربط التظليلات بالنص، وحسابات التقدم في القراءة

## ملاحظات حول البيانات

تم تجميع 174 صفحة مصدر من الكتاب في 163 قسماً/فصلاً بالاعتماد على `heading_index` الوارد
في الملف الأصلي. كل كتلة نصية تحتفظ برقم الصفحة الأصلية (`sourcePage`) لإمكانية تتبع الأصل.

## الميزات المُنفَّذة

قراءة RTL كاملة مع خطوط عربية متعددة، أوضاع قراءة (تمرير متصل / صفحات / أعمدة / تركيز)،
تظليل بالسحب مع تثبيت النص عبر السياق (prefix/suffix anchors)، ملاحظات، علامات مرجعية،
بحث فوري داخل الفصل والكتاب كاملاً (Fuse.js)، إحصائيات قراءة، سمات متعددة (ورقي/دافئ/سيبيا/رمادي/ليلي/أسود)،
تخصيص كامل للطباعة، قراءة صوتية (Web Speech API)، وضع تحرير ومراجعة للتصحيحات مع سجل إصدارات،
تصدير/استيراد البيانات، ودعم PWA للعمل دون اتصال.

## قيود معروفة

- وضع "الصفحات" (paginated) يستخدم تقسيماً تقريبياً بعدد الكلمات وليس قياس ارتفاع فعلي للعناصر.
- ميزة "تعريف الكلمة" غير موصولة بقاموس فعلي بعد (بحسب التعليمات: لا تختلق تعريفات).
- الأيقونات في `public/icons/` أيقونات مؤقتة بسيطة؛ يُنصح باستبدالها بتصميم نهائي قبل النشر.
